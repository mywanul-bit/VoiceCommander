# ভয়েস কমান্ডার — মুখে বললেই ফোন চলবে

**ভয়েস কমান্ডার** একটি ফ্রি অ্যান্ড্রয়েড অ্যাপ। মাইক বোতাম চেপে কথা বললেই ফোন অ্যাপ খুলবে, বন্ধ করবে, স্ক্রল করবে, কিবোর্ডে ক্লিক করবে, লিখবে — আর কাউকে মেসেজও পাঠাবে। হাত দিয়ে টাচ করতে হবে না।

## ইনস্টল করার নিয়ম

1. **GitHub থেকে APK নিন** — রিপোজিটরির **Actions** ট্যাবে গিয়ে সবশেষ সফল build-এর **voice-commander-debug** আর্টিফ্যাক্ট ডাউনলোড করুন (ZIP খুললে ভেতরে `app-debug.apk` থাকবে)।
2. ফোনে APK ফাইলটি খুলে ইনস্টল করুন। প্রথমবার “অজানা উৎস থেকে ইনস্টল” (Install unknown apps) অনুমতি দিতে হতে পারে।
3. অ্যাপ খুলে **“অনুমতি দিন”** বোতাম চাপুন — মাইক, কন্টাক্ট, কল আর ক্যামেরার অনুমতি দিন।
4. **“Accessibility সেবা চালু করুন”** বোতাম চাপুন — Accessibility সেটিংস খুলবে, সেখানে **ভয়েস কমান্ডার** খুঁজে চালু করুন। এটা ছাড়া অ্যাপ ক্লিক, টাইপ আর স্ক্রল করতে পারবে না।
5. **“সঠিক সময়ের অ্যালার্মের অনুমতি দিন”** বোতাম চাপুন — অ্যালার্ম যাতে ঠিক সময়ে বাজে, সেই অনুমতি চালু করুন। অনুমতি না থাকলে অ্যালার্ম সিস্টেমের ঘড়ি অ্যাপে বসিয়ে দেওয়া হবে।
6. বড় মাইক বোতাম চাপুন — “শুনছি…” লেখা উঠলেই কমান্ড বলুন।

**অ্যালার্ম কীভাবে বাজে:** সময় হলে ডিফল্ট অ্যালার্মের সুর বাজে, ফোন ভাইব্রেট করে আর নোটিফিকেশনে “বন্ধ করো” বোতাম আসে। “অ্যালার্ম বন্ধ করো” বললেও বন্ধ হয়। সঠিক সময়ের অনুমতি না থাকলে অ্যালার্ম সিস্টেমের ঘড়ি অ্যাপে বসিয়ে দেওয়া হয়।

**কিছু কাজ সরাসরি করা যায় না (অ্যান্ড্রয়েডের নিয়ম):** অ্যান্ড্রয়েড ১০ থেকে সাধারণ অ্যাপ ওয়াইফাই সরাসরি চালু/বন্ধ করতে পারে না — তাই অ্যাপ ওয়াইফাই প্যানেল খুলে টগলটি চেপে দেয়। ব্লুটুথও প্রথমে সরাসরি চেষ্টা করে, না পারলে প্যানেল খুলে দেয়। মোবাইল ডাটা আর এয়ারপ্লেন মোড কোনো সাধারণ অ্যাপই সরাসরি বদলাতে পারে না — অ্যাপ শুধু সেটিংস পাতা খুলে দেয়, টগলটি সেখানে চাপতে হয়।

**মেসেজ কীভাবে যায়:** নামটি ফোনের কন্টাক্ট থেকে খুঁজে নম্বর বের করা হয়। হোয়াটসঅ্যাপ থাকলে হোয়াটসঅ্যাপ চ্যাট খুলে মেসেজ লিখে সেন্ড টিপে দেওয়া হয়। হোয়াটসঅ্যাপ না থাকলে SMS অ্যাপ খুলে নম্বর আর মেসেজ বসিয়ে দেওয়া হয়।

## যা যা লাগে (সব ফ্রি)

- অ্যান্ড্রয়েড ৮.০ বা তার বেশি (minSdk 26)
- ইন্টারনেট (ভয়েস চিনতে গুগলের সেবা ব্যবহার হয়)
- মাইক + কন্টাক্ট + ক্যামেরা + Accessibility অনুমতি
- সঠিক সময়ের অ্যালার্মের অনুমতি (সেটিংস থেকে একবার দিতে হয়)
- ব্রাইটনেস বদলাতে সেটিংসে লেখার অনুমতি (প্রথমবার চাইলে সেটিংস খুলে দেবে)
- GitHub অ্যাকাউন্ট (APK বানাতে) — কোনো টাকা লাগে না

## নিজে APK বানাতে চাইলে

রিপোজিটরি `main` ব্রাঞ্চে push করলেই GitHub Actions নিজে থেকে `assembleDebug` চালিয়ে APK বানায়। কোডে কোনো সার্ভার বা পেইড সেবা নেই।

## ফাইলগুলো

- `app/src/main/java/com/mywanul/voicecommander/` — MainActivity, VoiceCommandService, CommanderAccessibilityService, CommandParser, CommandExecutor, AppResolver, ContactHelper, DeviceControl (অ্যালার্ম, টর্চ, ওয়াইফাই, ব্লুটুথ, ভলিউম, ব্রাইটনেস)
- `app/src/main/AndroidManifest.xml` — permissions ও সার্ভিস ঘোষণা
- `app/src/main/res/xml/accessibility_service_config.xml` — Accessibility সেবার সেটিং
- `.github/workflows/build.yml` — ফ্রি GitHub Actions build
